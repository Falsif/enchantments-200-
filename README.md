# Break Everywhere — Fabric 1.21.1

Сломал блок — такой же блок ломается **во всех загруженных чанках мира**.
- Сломал листву — пропадает **вся листва** (дуб, берёза, ель... все виды).
- Сломал бревно — пропадают **все брёвна**, деревья остаются без стволов.
- Сломал камень, землю, песок, руду — то же самое для этого блока.
- Предметы выпадают на месте каждого блока (с учётом инструмента: Удача, Шёлковое касание работают на весь мир).

## Установка
`.minecraft/mods`: `breakeverywhere-1.0.0.jar` + **Fabric API** для 1.21.1. Для сервера достаточно поставить на сервер.

## Как работает
- Ломается волной от игрока к дальним чанкам. За тик мод тратит не больше 25 мс, поэтому игра не зависает, даже если сломать камень.
- В строке над хотбаром виден прогресс: «Ломаю Камень: 120000 блоков, чанк 300/900».
- Загруженные чанки — это область вокруг игроков (дальность прорисовки). Чанки, которые загрузятся потом, не трогаются.
- Первые 3000 блоков роняют предметы каждый на своём месте; дальше дроп каждого чанка собирается в стаки в одной точке чанка, иначе миллионы предметов уронят игру.
- В творческом режиме, как и в обычной игре, предметы не выпадают (можно включить `dropsInCreative`).
- Никогда не ломаются: бедрок, порталы, рамки порталов Края, барьеры, командные блоки, спавнеры, хранилища.

## Команды (оператор)
```
/breakall         — статус
/breakall on|off  — включить / выключить мод
/breakall stop    — остановить идущие волны
/breakall reload  — перечитать config/breakeverywhere.json
```

## Настройки `config/breakeverywhere.json`
| Ключ | По умолчанию | |
|---|---|---|
| `enabled` | true | мод включён |
| `groupAllLeaves` | true | любая листва = вся листва |
| `groupAllLogs` | true | любое бревно = все брёвна |
| `dropItems` | true | выпадают предметы |
| `dropsInCreative` | false | дроп и в творческом |
| `maxSeparateDrops` | 3000 | после этого дроп собирается в стаки по чанкам |
| `millisPerTick` | 25 | время на ломание за тик |
| `updateNeighbors` | true | песок падает, факелы отваливаются, вода течёт |
| `showProgress` | true | прогресс над хотбаром |
| `blacklist` | см. выше | блоки, которые не ломаются везде |
