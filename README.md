# Enchantments 200 — Fabric 1.21.1

Все оригинальные зачарования Minecraft до **200 уровня (CC)**, и каждый уровень реально усиливает эффект.
Ни одно ванильное зачарование не заменено: мод только поднимает максимальный уровень и снимает ограничения.

## Установка
1. Minecraft **1.21.1** + **Fabric Loader** (https://fabricmc.net/use/installer/).
2. В папку `.minecraft/mods` положить:
   - `enchantments200-1.0.0.jar` (этот мод);
   - **Fabric API** для 1.21.1 (https://modrinth.com/mod/fabric-api).
3. Для сервера мод ставится на сервер; на клиент тоже желательно (римские цифры, названия книг, вкладка творчества).

## Что даёт уровень 200
| Зачарование | Эффект на CC |
|---|---|
| Острота | +100,5 урона (Острота V = +3) |
| Небесная кара / Бич членистоногих | +500 урона по своим мобам |
| Защита (и огне-/взрыво-/снарядозащита) | ~96% меньше урона с одного предмета, до 99% с полной брони (ваниль: максимум 80%) |
| Невесомость | почти нет урона от падения |
| Эффективность | мгновенная добыча |
| Удача | в среднем ~95 алмазов с руды (тест: 2827 с 30 руд) |
| Прочность | износ ~0,6% от обычного |
| Добыча | намного больше лута с мобов |
| Сила | ~+100 урона стрелы |
| Отбрасывание / Откидывание | очень сильное (ограничено 30 уровнем эффекта, чтобы мобы не улетали в незагруженные чанки) |
| Заговор огня / Горящая стрела | огромное время горения |
| Подводное дыхание, Скорость души, Пронзатель и др. | растут с уровнем |

Зачарования «да/нет» (Шёлковое касание, Бесконечность, Починка, Подводник, Проклятия, Тягун) работают так же, как в ванили, — у них нет силы, которая могла бы расти; им просто можно поставить любой уровень.

### Защита от вылетов
Некоторые эффекты на 200 уровне ломают игру (Ледоход замораживает ~125 000 блоков каждый шаг, Тягун выкидывает за пределы мира, Тройной выстрел даёт 400 стрел). Для них эффект перестаёт расти на безопасном уровне, хотя на предмете виден настоящий уровень:
Ледоход 16, Тягун 10, Верность 10, Тройной выстрел 16, Быстрая перезарядка 4, Приманка 5, Порыв ветра 10, Пробитие 6, Отбрасывание 30, Откидывание 30, Скорость души 20.
Всё меняется в `config/enchantments200.json` (`effectLevelCaps`, 0 = без ограничения).

## Наковальня
- Нет «Слишком дорого!»: стоимость не выше 30 уровней опыта (`anvilMaxCost`).
- Две книги (или предмет + книга) с одним зачарованием **складываются**: CC = C + C, 128 = 64 + 64. Так из Остроты I за 8 шагов получается CC.
- Перенос зачарований на оружие, броню и инструменты — как обычно.
- `"anvilMergeMode": "vanilla"` возвращает обычное V + V = VI.

## Стол зачарований, жители, сундуки
По умолчанию дают обычные ванильные уровни (Острота V и т.д.), чтобы не ломать выживание. Высокие уровни — через наковальню, команды и творческий режим. `"vanillaLevelsForNaturalLoot": false` — пусть и стол/жители/сундуки дают до CC.

## Команды
```
/enchant200 help                                  — список команд
/enchant200 list                                  — все зачарования (клик = команда выдачи)
/enchant200 give <игрок> <зачарование> [уровень]  — выдать книгу
/enchant200 max [зачарование]                     — книга макс. уровня (без аргумента — все книги)
/enchant200 apply <зачарование> [уровень]         — зачаровать предмет в руке
/enchant200 reload                                — перечитать настройки
```
Пример: `/enchant200 give Steve sharpness 200`. Нужны права оператора (кроме help и list).

## Творческий режим
Вкладка **«Зачарования 200»**: книги каждого зачарования уровней I, V, X, XXV, L, C, CL, CC.
Книги называются «Книга: Острота CC», в описании видно «Уровень 200 / 200».

## Настройки `config/enchantments200.json`
| Ключ | По умолчанию | Что делает |
|---|---|---|
| `maxLevel` | 200 | максимальный уровень (1–255; 255 — предел формата предметов Minecraft) |
| `anvilMergeMode` | `sum` | `sum` или `vanilla` |
| `removeTooExpensive` | true | убрать «Слишком дорого!» |
| `anvilMaxCost` | 30 | макс. цена наковальни в уровнях |
| `vanillaLevelsForNaturalLoot` | true | ванильные уровни у стола/жителей/сундуков |
| `protectionMaxReduction` | 0.99 | предел снижения урона от защиты |
| `prettyBookNames` | true | названия «Книга: …» |
| `effectLevelCaps` | см. выше | безопасные пределы эффектов |

## Совместимость
- Зачарования хранятся в обычном формате Minecraft — сохраняются в мире, работают на сервере и в одиночной игре.
- Зачарования из других модов тоже получают максимум 200 (если у них был больше — остаётся их).
- Если удалить мод, предметы останутся с уровнями до 200 (Minecraft это поддерживает), просто вернутся ванильные ограничения.

## Сборка
`./gradlew build` (нужен JDK 21) → `build/libs/enchantments200-1.0.0.jar`.
GitHub Actions собирает мод и запускает автотест на настоящем сервере 1.21.1 (`gradle runSelftest`), отчёт — `selftest-report.txt` в релизе.
